FS2 + SO1 · replaces the six-up portrait grid

Applications as a wide-format loop, not six fixed boxes.

The portrait grid was the client's biggest objection, and it was two objections in one: the grid reads as static, and six framed boxes read as an exhaustive list of what WS Technicals can build. A moving wide-format row solves both — the images get the format they were shot for, and a row that keeps travelling cannot be read as a closed set of six.

"Applikationerne fungerer bedre i bredformat, og et grid bliver meget statisk. Kan vi få noget dynamik ind på siden ved at erstatte højformats-gridded med en bredformats 'slider', hvor billederne kører i et loop el.lign.?"

FS4 · needs new assets

Supplier logos in colour.

Correction — I had this wrong. I first called this a one-line CSS fix. It is not. All ten logo files the site uses are flattened to a single colour, #06081a — the site's own --ink token. The colour is not in the files, so dropping the saturate(.72) filter changes almost nothing; the two panels below are near-identical for exactly that reason.

Partial colour originals do exist in the repo: technology-partners-strip.png holds all ten in one 2500×110 strip with seven of them in colour, and eve/highstar/rept/spe.png are 220×110 on white. Neither source is big enough for the 190×58 slot on a high-density screen, so the real fix is to request colour logos — ideally SVG — from the seven suppliers that have them.

"Supplier logos må meget gerne være i farver."
