UPS platform, in Blender.

Same scroll-theatre treatment run against pack-ups-platform.html's own model (assets/models/wl03.fbx) — a 19-inch rack unit. Callout keywords and tiers ported from this platform's own entry in product-3d-showcase.js (MODELS['ups']), not re-derived.

This one hit a real bug worth flagging: this FBX (unlike the other three) carries baked keyframe animation on every object in its hierarchy, a leftover from the original CAD export. It was silently resetting every position edit between when the explode was applied and when Cycles actually rendered — the geometry measured correctly in Python but rendered as if nothing had moved. Fixed by clearing animation data from all 571 objects immediately after import.
