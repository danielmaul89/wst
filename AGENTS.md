# WS Technicals website instructions

Read `DESIGN-SYSTEM.md` before editing the site.

- Shared visual rules live in `assets/styles/wst-design-system.css`.
- Shared motion and glass details live in `assets/styles/enterprise-polish.css`.
- Shared navigation and footer markup live in `assets/scripts/wst-shell.js`.
- Page-level CSS is only for unique section layouts.
- Use the established typography scale, tokens, `.container`, shared buttons, navigation, forms and footer.
- Preserve accessibility, responsive behaviour and reduced-motion support.
- Make global changes once in the shared system, not repeatedly in individual pages.
- Keep unrelated working-tree changes intact.
